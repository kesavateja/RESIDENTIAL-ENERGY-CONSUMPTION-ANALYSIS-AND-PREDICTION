# RESIDENTIAL-ENERGY-CONSUMPTION-ANALYSIS-AND-PREDICTION
🏡 Project: Residential Energy Consumption Analysis and Prediction
I’m excited to share my Data Science project, Residential Energy Consumption Analysis and Prediction, developed using the U.S. Residential Energy Consumption Survey (RECS) 2015 dataset.
📌 Project Overview:
The objective of this project is to analyze residential energy consumption patterns and apply Machine Learning algorithms to predict household energy consumption and air-conditioning usage.
🛠️ Technologies & Tools Used:
• Python
• Pandas & NumPy
• Matplotlib & Seaborn
• Scikit-learn
• Jupyter Notebook
🤖 Machine Learning Models Implemented:
Regression Models:
• Multiple Linear Regression
• Polynomial Regression
Classification Models:
• Logistic Regression
• K-Nearest Neighbors (KNN)
📊 Key Results:
• Polynomial Regression achieved an R² score of approximately 52.11%.
• Multiple Linear Regression achieved an R² score of approximately 50.09%.
• Logistic Regression achieved an accuracy of approximately 88.07%.
• KNN achieved an accuracy of approximately 86.51%.
🔍 Key Activities:
• Data cleaning and preprocessing
• Exploratory Data Analysis (EDA)
• Outlier detection using the IQR method
• Correlation analysis and data visualization
• Machine Learning model training and evaluation
💡 What I Learned:
This project helped me gain practical experience in data preprocessing, statistical analysis, data visualization, and implementing Machine Learning algorithms using Python.
